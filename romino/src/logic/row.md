# Row

Column placement, validity, return-to-bar. `pushBelowCost` > 0 (requires `starPowers` ON): `stack-below` slot (push from below, costs N stars); deduped when top-stack also valid. Push completing a 3-dice stack runs the same `passesNoDuplicateTile` gate as top completion, on `[push, v0, v1]` (push lands at index 0). `passesOuterBottomGuard` — when push enabled: outer bottom blocks top-stack except Bugger Singles outer-on-outer on all-outer columns. `buggerSingles` ON (requires `pushBelowCost` > 0): new columns may start with 1/6; `buggerPendingCols` blocks non-outer top-stack on pending singles; `buggerOuterStackLockedCols` blocks convert until push-below unlocks (2+ all-outer stacks stay locked through top-cap to 3). `switcherJokers` ON: standard tricolor third-die completion skips joker row/suit caps; duplicate triple gate only (no tile-identity duplicate checks). `diceAndCubes` ON: gap inserts may sit next to a tile (row edge or stack neighbor); tile↔tile gaps still blocked via `gapAllowsInsert`. `nextMustFollow` ON: when any lone-die stack matches the placed die’s value, gap-insert and new-column slots are blocked; stacking on any valid column remains allowed (bar or row reposition). Lone-die detection ignores the die being repositioned so the rule still applies when dragging the top die off a 2-dice stack. Jokers: when `tricolorRestriction` ON (default), `rowHasJoker` — at most one committed joker (tile or full tricolor stack) on the row at a time; spent-suit full stacks do not count; 2-dice stacks no longer gate other columns (`jokerSuitBlocked` still blocks same suit). `jokerSuitsUsed` / `jokerSuitBlocked` — at most one joker per suit per game. When OFF, those caps are lifted; duplicate 3-dice permutations (`rowHasMatchingThreeDiceStack`) and same convert identity (`rowHasMatchingConvertIdentity`) still block tricolor joker completion. `rowHasThreeDiceStack()` — any convert-ready 3-dice stack on the row. `isAtSpotCap()` — row columns only (between-zone strip excluded). Deck-flank stacks are virtual (not in row). `isTrayStuck()` — active bar dice remain but none have a legal slot. `passesNoDuplicateTile` blocks convert identities matching strip tiles or row tiles (`identityBlockedByStripOrRow`) and, when `nineCubes` ON, cube locks (`isCubeLockedForIdentity`). `wouldCompleteBlockedDuplicate()` / `convertIdentityForStackCompletion()` — duplicate-block feedback UX. `wouldCompleteBlockedCube()` / `cubeLockColForStackCompletion()` — nine-cubes lock feedback UX. `monotonic` + `diceAndCubes` ON: wheel-based zone gate (`monotonic.js`); segment = outside-left / between consecutive anchors / outside-right; ace 1|13 per check Ace/joker stack completion requires stars when `aceJokerStarCost` ON (incl. switcher tricolor when ON). `canReturnDieToBar` — this-turn dice return from the top of a stack, from the bottom when push-below, or from the bottom of a 2-die stack (a swap can leave a this-turn die under a settled die); `returnDieToBar` refunds push-below / swap / flip stars as applicable.
