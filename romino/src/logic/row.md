# Row

Column placement, validity, return-to-bar. `starPowers` ON: `stack-below` slot (push from below, costs star); deduped when top-stack also valid. Push completing a 3-dice stack runs the same `passesNoDuplicateTile` gate as top completion, on `[push, v0, v1]` (push lands at index 0). `passesOuterBottomGuard` — a column whose bottom die is an outer 1/6 accepts nothing on top (inner or outer); the only legal way onto it is a push underneath, so no stack ever reads an outer bottom. `buggerSingles` ON (requires starPowers): new columns may start with 1/6; `buggerPendingCols` blocks top-stack until push-below. `switcherJokers` ON: standard tricolor third-die completion skips joker row/suit caps; duplicate triple gate only (no tile-identity duplicate checks). `diceAndCubes` ON: gap inserts may sit next to a tile (row edge or stack neighbor); tile↔tile gaps still blocked via `gapAllowsInsert`. `nextMustFollow` ON: when any lone-die stack matches the placed die’s value, gap-insert and new-column slots are blocked; stacking on any valid column remains allowed (bar or row reposition). Lone-die detection ignores the die being repositioned so the rule still applies when dragging the top die off a 2-dice stack. Jokers: when `tricolorRestriction` ON (default), `rowHasJoker` — at most one committed joker (tile or full tricolor stack) on the row at a time; spent-suit full stacks do not count; 2-dice stacks no longer gate other columns (`jokerSuitBlocked` still blocks same suit). `jokerSuitsUsed` / `jokerSuitBlocked` — at most one joker per suit per game. When OFF, those caps are lifted; duplicate 3-dice permutations (`rowHasMatchingThreeDiceStack`) and same convert identity (`rowHasMatchingConvertIdentity`) still block tricolor joker completion. `rowHasThreeDiceStack()` — any convert-ready 3-dice stack on the row. `isAtSpotCap()` — row columns only (between-zone strip excluded). Deck-flank stacks are virtual (not in row). `isTrayStuck()` — active bar dice remain but none have a legal slot. `passesNoDuplicateTile` blocks convert identities matching strip tiles or row tiles (`identityBlockedByStripOrRow`) and, when `nineCubes` ON, cube locks (`isCubeLockedForIdentity`). `wouldCompleteBlockedDuplicate()` / `convertIdentityForStackCompletion()` — duplicate-block feedback UX. `wouldCompleteBlockedCube()` / `cubeLockColForStackCompletion()` — nine-cubes lock feedback UX. `monotonic` + `diceAndCubes` ON: wheel-based zone gate (`monotonic.js`); segment = outside-left / between consecutive anchors / outside-right; ace 1|13 per check Ace/joker stack completion requires stars when `aceJokerStarCost` ON (incl. switcher tricolor when ON).
